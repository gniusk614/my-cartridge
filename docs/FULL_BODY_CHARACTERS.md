# 전신 캐릭터와 적 이미지 · 자동 동작 1.3

2026-11-11부터 플레이어·이야기의 상대·NPC·적 모두에 전신 이미지를 적용한다. 얼굴만 바꾸는 기존 템플릿과 별도로, 원본의 머리·옷·팔·다리·신발을 사용해 대기·이동·공격·점프·앉기·피격·쓰러짐 시트를 자동 생성한다. 전투 규칙·타격 판정·스토리·진행 저장은 유지한다.

## 가장 빠른 사용법

1. [스튜디오](https://gniusk614.github.io/my-cartridge/studio/)의 **캐릭터 공방**에서 편집할 캐릭터 또는 적을 고른다. **맵과 장면**에서 시작점·적·대화 인물을 선택해도 같은 편집기가 열린다.
2. **＋ 전신 이미지 선택**으로 PNG·JPEG·WebP를 고른다. 원본 전체를 축소·도트화하고 부위 경계를 추정한 뒤 7개 동작을 생성해 해당 인물에 즉시 적용한다. **샘플 전신으로 테스트**로 사진 없이 먼저 확인할 수 있다.
3. **동작 미리보기**에서 걷기·공격 등을 확인한다. **부위 경계 · 색상 · 크기 조정**에서 머리 아래·허리·몸통 너비·중심·방향·색상 수·배경 제거를 조절하고 **동작 다시 생성해 적용**을 누른다. 게임 안 그림 높이도 조절할 수 있다.
4. **플레이**로 실제 게임을 확인한다. **스프라이트시트 PNG 받기**는 그림만, **JSON 저장**은 원본·설정·연결까지 보관한다. **게임 ZIP**은 고객 에피소드와 실행 파일을 함께 전달한다.

전신은 머리부터 신발까지 보이며 팔다리가 구분되는 투명 PNG가 가장 적합하다. 단색 배경 제거는 가장자리와 이어진 비슷한 색을 지우는 보조 기능이다. 투명 PNG의 어두운 옷을 배경으로 지우지 않는다. 복잡한 사진 배경은 미리 제거하는 편이 좋다.

## 생성 방식과 한계

브라우저 Canvas에서 원본을 머리·몸통·양팔·양다리로 분할하고 회전·이동·크기 변화를 주는 **컷아웃 애니메이션**이다. 원본의 전체 실루엣을 사용하므로 얼굴뿐 아니라 복장과 신발도 바뀐다. 색상은 원본 또는 8·16·32·64색을 선택한다. 부위 분할선은 투명 영역을 제외한 인물 범위에 대한 비율이다.

AI 재그림이나 해부학적 자세 추론은 아니다. 가려진 팔·다리, 원본에 없는 뒷모습·새로운 시점은 만들지 않는다. 정면 그림은 정면 형태로 움직이며, 오른쪽을 기본으로 왼쪽은 반전한다. 얼굴 사진만 넣으면 새 몸을 만들어 주지 않는다. 팔다리가 몸에 겹치거나 옷이 넓게 퍼진 이미지에는 분할 자국·늘어남이 생길 수 있다. 경계를 조정하거나 완성된 외부 시트를 사용한다.

스프라이트 PNG는 96×96 칸, 8열×7행, 전체 768×672다. 행 순서는 대기·이동·공격·점프·앉기·피격·쓰러짐이며 유효 프레임 수는 각각 4·8·6·4·2·2·4다. 게임 표시 높이는 기본 48, 허용 범위는 16~96이다. 그림 크기와 동작은 피해량·이동 속도·점프 물리·피격 영역을 바꾸지 않는다. 모바일에는 앉기 버튼을 추가하지 않으며 기존 키보드 앉기는 유지한다.

## 재사용·원본 보관

- **에셋 보관함 → 전신 원본 (자동 생성용)**으로 이미지를 등록한 뒤 캐릭터·적 적용 대상을 골라 **전신 동작 자동 생성**을 누를 수 있다. **캐릭터 동작** 시트는 여러 인물에 공유할 수 있다.
- 공유 중인 시트를 다시 생성하면 선택한 인물용 시트를 새로 만든다. 다른 인물의 그림은 유지한다. 새 전신 이미지를 올릴 때 기존 원본 에셋을 덮어쓰지 않는다. 같은 원본으로 경계만 조정하면 해당 원본을 재사용한다.
- 전신 원본은 긴 변 최대 384픽셀 PNG로 보관한다. 업로드 파일 자체는 전송하지 않지만, **축소한 전신 PNG는 초안·JSON·ZIP에 포함**된다. 원본 PNG와 생성 설정을 보관하므로 다시 열어 재생성할 수 있다. 외부 API 호출이나 서버 업로드는 없다.
- 전신 원본과 생성 시트는 각각 에셋 한 개를 차지한다. 프로젝트 전체 32개, PNG base64 합계 12,000,000자·8,388,608픽셀 한도를 적용한다. **연결되지 않은 에셋 정리**는 인물이 사용하는 시트와 그 원본을 함께 보존하고, 어느 인물도 쓰지 않는 시트·원본을 정리한다.

기존 초상화·색상·얼굴 템플릿은 **기본 도형 외형 · 대화 초상화 · 기존 시트 설정**에 남아 있다. 완성된 외부 PNG는 **등록된 동작 시트로 바꾸기 · 기본 외형 복원**에서 연결하고 칸 크기·동작 메타데이터를 편집한다. 외부 시트 구입은 필수가 아니다.

## 호환성과 검증

새 제작 팩은 1.3.0이며 1.0.0·1.1.0·1.2.0도 계속 읽는다. 생성 정보는 sprite_sheet의 `generation`, 표시 높이는 `display_height`, 보관 원본 종류는 `character_source`다. 계약은 [DATA_CONTRACT.md](DATA_CONTRACT.md)를 따른다.

단위 검사에서 실루엣 누락·동작 차이·팔레트·배경 처리·원본 참조·잘못된 생성 정보를 검사한다. Chromium·WebKit에서 서로 다른 플레이어/적 복장과 신발 픽셀, 실제 게임 적용, 공유 시트 재생성·실행 취소·재불러오기, 좁은 터치 화면의 적 추가·자동 생성을 확인한다. 기존 조이스틱·멀티터치·전투·저장·고객 ZIP 검사도 유지한다. 실제 고객 이미지별 동작 품질은 제작자가 미리보기에서 확인한다.
