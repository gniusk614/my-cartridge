# 너에게로 가는 길 · 생일 반전 에피소드

아내가 주인공이며 아기를 안고 바이러스를 물리치면서 집까지 간다. 아기용품과 익숙한 옛 물건 사이에서 사진 조각 6개를 찾는다. 마지막 집에서 사진을 완성하면 품 안의 아이가 아내의 아기 시절 모습이었다는 사실이 드러나고, “태어나줘서 고마워”로 시작하는 생일 편지와 현재 가족 사진으로 끝난다.

## 바로 제작·플레이

[생일 예제로 스튜디오 열기](https://gniusk614.github.io/my-cartridge/studio/?template=birthday)를 사용하거나 에피소드 탭의 **생일 반전 예제로 시작**을 누른다. 기존 초안을 저장하고 별도 팩 ID의 새 제작 원본을 만든다. 로컬 주소는 `http://127.0.0.1:8765/studio/?template=birthday`다.

1. **캐릭터 공방**에서 ‘당신’과 ‘남편’의 이름·외형을 바꾼다. 사람형 기본 도트 캐릭터가 들어 있으며 전신 이미지나 ChatGPT 동작 시트로 교체할 수 있다.
2. **스토리 → 사진 조각과 생일 반전 엔딩**에서 **아내의 아기 시절 사진 넣기**, 이름·태어난 날짜, 반전 대사, **마지막 현재 가족 사진 넣기**를 설정한다. 사진 등록 전에는 샘플 일러스트로 실행한다.
3. 각 장면의 기억을 실제 옛 물건과 추억으로 바꾼다. **기억에 옛날 사진 넣기**는 선택 항목이다. 반전용 아기 사진은 마지막에만 공개하도록 일반 기억 사진과 분리한다.
4. **플레이**로 세 장면을 확인한다. **JSON 저장**은 다시 편집할 원본, **게임 ZIP**은 HTTP/HTTPS 호스팅에서 실행할 고객 게임이다.

사진은 브라우저에서 긴 변 최대 1024픽셀 PNG로 변환하며 초안·JSON·ZIP에 포함된다. 실제 이름·생일·가족 사진을 서버나 공개 GitHub에 자동 게시하지 않는다. 공개 예제에는 실제 가족 자료가 없으며, 이름 ‘당신/남편’과 대체 가능한 도형 캐릭터·샘플 일러스트만 사용한다.

## 플레이 흐름

| 장면 | 전투와 탐색 | 기억 |
|---|---|---|
| 품 안의 작은 온기 | 바이러스 2마리, 작은 발판, 아기 안기, 남편 동행 | 작은 양말, 낯익은 딸랑이 |
| 어디선가 본 놀이터 | 바이러스 2마리, 도착 이벤트 이후 두 번째 적 등장 | 오래된 인형, 꽃무늬 벽지 |
| 마지막 문 앞에서 | 바이러스와 체력 100의 큰 그림자. 그림자는 공격 준비 시간이 더 길다 | 접힌 사진 조각, 마지막 사진 조각 |

각 장면에서 첫 적 처치 후 첫 조각, 남은 적 처치 후 두 번째 조각을 찾는다. 첫 조각을 찾은 뒤 대화를 마치면 보호 체력 18을 회복한다. 남편은 주인공 뒤를 따라오며 가까이서 살피면 대화한다. 전투 판정은 기존 이동·점프·3타 연계·피격 규칙을 사용한다. 아기를 안은 그림은 플레이어에 붙는 표현이며 별도의 아기 피해·사망 판정은 없다.

모든 기억을 모은 뒤 오른쪽 문에서 살피면 다음 장면으로 이어진다. 기존 카페 실내를 거치지 않는다. 마지막 문에서는 다음 순서를 따른다.

1. 모아 온 사진 조각을 하나씩 액자에 놓는다.
2. 전부 놓은 뒤 **사진 뒷면 보기**로 사진 속 이름·날짜·정체 대사를 공개한다.
3. **편지 읽기**에서 “태어나줘서 고마워”와 생일 편지를 읽는다.
4. **우리의 오늘**에서 현재의 가족 사진으로 마무리한다.

사진의 이름·날짜·반전 대사는 수집 중 대사와 기억 앨범에 자동 삽입하지 않는다. 제작자가 직접 도입·기억에 결말을 적으면 먼저 드러날 수 있으므로 콘텐츠도 확인한다. 조각 조립 도중 종료하면 모은 조각은 유지되며 마지막 문에서 다시 조립한다. 편지를 읽으면 기존 `ending_seen` 사실을 저장한다.

## 스토리·이벤트 편집기

이 기능은 생일 이야기 밖의 에피소드에도 사용한다. 스토리 탭에서 **＋ 이벤트 추가** 후 조건·선행 이벤트·대사·화자·회복량을 설정한다.

- 조건: 장면 시작, 특정 X 위치 도착, 특정 적 처치, 특정 기억 획득, 장면 목표 완료.
- 여러 선행 이벤트를 지정하면 모두 완료된 뒤 실행한다. 목록 순서대로 실행 가능한 이벤트를 하나씩 보여 준다.
- 대화의 **계속 걷기**를 눌렀을 때 회복과 이벤트 완료를 함께 저장한다. 대화 도중 종료한 이벤트는 다시 보여 주며, 완료한 이벤트와 회복은 반복하지 않는다.
- **적 등장 연결**에 이벤트를 지정하면 기존 X 위치·선행 적 처치 조건과 이벤트 완료를 모두 만족해야 적이 등장한다.
- **출입구를 사용하면**에서 기존 카페 진입과 다음 장면/엔딩 직접 연결을 고른다.
- **주인공이 아기를 안고 이동**, **함께 따라오는 인물**을 설정할 수 있다. 동행 인물은 먼저 해당 맵의 대화 인물로 배치한다.

같은 장면 안에서 이벤트·적·기억 조건을 연결한다. 없는 대상·다른 장면 대상·순환 조건·자기 등장을 막는 처치 조건은 검증에서 거부한다. 같은 유형 적 일부를 처치해 기억을 얻고 그 기억으로 다음 적을 여는 흐름도 허용한다. 이벤트는 코드나 외부 URL을 실행하지 않는다.

현재의 동행 인물은 이동·대화 역할이며 자동 전투 AI는 없다. 기본 전투 아트와 사진 대체 그림은 개발용이다. 실제 가족 사진과 최종 인물 아트로 교체한 뒤 난이도·추억의 정확성·반전 타이밍을 직접 플레이해 확인한다.
