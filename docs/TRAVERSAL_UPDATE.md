# 점프와 건물 탐색 추가

사용자 피드백에 따라 점프·앉기·건물 출입·발판에서 난간에 올라가는 탐색 동작을 추가했다. 음원과 사운드 에셋은 변경하지 않았다. 이 문서가 기존 검토·검증 기록의 이동 및 엔딩 흐름을 갱신한다.

벨트스크롤의 x/y는 지면 위치로 유지하고 elevation을 별도로 계산한다. 점프 중에는 그림자가 지면에 남고 캐릭터만 위로 올라간다. 하강할 때 발밑 발판 높이를 가로지르면 그 위에 착지하고, 발판 끝을 걸어 나가면 다시 떨어진다. 발판 아래에서 옆으로 걸어 들어갈 수 없으며 전투도 높이가 14px 넘게 다르면 맞지 않는다.

현재 거리 템플릿에는 x 300~332, y 104~121의 높이 16px 상자와 x 355~515, 같은 깊이 범위의 높이 50px 난간을 둔다. 점프 최대 높이는 약 41px이므로 지면에서 난간으로 바로 오를 수 없고 상자를 디뎌야 한다. 탐색은 선택 사항이며 기본 완주 경로를 잠그지 않는다. 발판 배치는 현재 템플릿 코드에 속한다. 이번 변경은 JSON 형식을 바꾸지 않았다.

앉기는 K/Ctrl 또는 화면 버튼을 누르는 동안 몸을 낮추고 이동 속도를 35%로 줄인다. 앉은 상태에서는 공격할 수 없고, 버튼을 떼면 일어난다. 무적이나 회피 판정은 부여하지 않았다. Space는 공격에서 점프로 변경했고 공격은 J에 남겼다.

오른쪽 카페 문 근처에서 E로 내부에 들어가고, 내부 하단 문에서 E로 밖으로 나온다. 실내에서는 외부 적의 물리 처리를 멈춰 보이지 않는 공격을 방지하고, 나올 때 적 상태를 복원한다. 단서가 모두 모이면 내부 창가 책상에서 E로 편지를 읽고 엔딩을 연다. 단서 수집 전에는 안내만 표시한다. 단순히 거리 오른쪽에 도착하면 자동으로 엔딩이 열리던 이전 동작을 대체했다.

저장 형식은 유지했다. 실내 위치나 공중 위치는 저장하지 않으며 재접속·재시도 시 거리 입구에서 진행 사실을 복원한다. 화면 버튼에도 점프와 앉기를 추가했고 팝업·일시정지 시 해당 입력과 공중 높이도 멈춘다.

## 자동 검증

Godot 4.7.2 실제 물리 프레임에서 71개 검사가 통과했다. 기존 세 팩 10회 완주는 이제 문 진입·내부 이동·책상 상호작용까지 포함한다. 카페 팩 838, 우산 팩 1022, 일출 팩 896 물리 프레임으로 완주했다.

추가 검사는 실제 점프 입력으로 상자 착지·상자에서 난간 착지·난간 위 이동·가장자리 낙하, 지면에서 높은 난간 직접 진입 거부, 앉기와 공격 차단·해제, 점프 도중 정지, 카페 출입과 진행 보존, 높이 차이 타격 거부를 확인한다. 살아 있는 외부 적의 실내 정지·퇴실 후 복원, 단서 수집 전 편지 잠금도 검사했다.

로컬 웹 브라우저에서도 키보드 점프로 상자와 난간에 올라가고, 난간에서 이동해 카페 내부로 들어가는 동작을 직접 확인했다. 확인한 warn/error 로그는 0개였다. 사람의 점프 조작감과 모바일 동시 터치는 여전히 실기기 확인이 필요하다.
