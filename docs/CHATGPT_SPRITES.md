# ChatGPT 스프라이트시트 가져오기

펭귄·동물·마스코트는 사람 비율로 머리·몸통·팔다리를 나누면 그림이 갈라질 수 있다. 이런 캐릭터는 **ChatGPT에서 체형에 맞는 동작을 새로 그리고 스튜디오로 가져오는 방식**을 사용한다. 별도 API 키·생성 서버를 연결하지 않는다. 스튜디오가 ChatGPT 계정을 자동 사용하거나 이미지 생성을 자동 호출하지는 않는다.

## 사용 순서

1. **캐릭터 공방**에서 플레이어·NPC 또는 적을 고른다. **ChatGPT로 캐릭터에 맞는 동작 그리기**에서 **참조 이미지 선택**으로 펭귄 등의 원본을 준비한다. 기존 전신 원본도 사용할 수 있다. **캐릭터 특징**에 종·복장·공격 방식 등을 적는다. 예: `둥근 펭귄, 빨간 목도리, 짧은 발로 뒤뚱뒤뚱 걷기, 날개로 공격`.
2. **참조 PNG 받기**와 **ChatGPT 요청문 받기/요청문 복사**를 사용한다. **ChatGPT 열기**로 이동해 PNG와 요청문을 함께 첨부하고 이미지를 생성한다. 결과 PNG를 저장한다. 생성 가능 여부·횟수는 사용 중인 ChatGPT 계정에 따른다.
3. 스튜디오로 돌아와 **＋ 생성된 동작 시트 넣기**에 PNG를 넣는다. **가져온 동작**에서 7개 동작을 확인한다. 이 시점에는 게임 외형을 바꾸지 않는다. **확인한 시트 적용**을 누른 뒤 **플레이**, **JSON 저장**, **게임 ZIP**으로 확인·보관한다.

스튜디오는 참조 이미지·요청문을 외부로 자동 전송하지 않는다. ChatGPT에 첨부하는 단계는 제작자가 직접 한다. 이 패널에서만 고른 참조와 캐릭터 특징은 임시 작업 상태이며 프로젝트 전환·새로고침 시 다시 준비한다. 전신 원본으로 등록한 이미지는 기존 프로젝트 초안·JSON 보관 규칙을 따른다.

## 시트 형식

- 기본 **4열·7행**, 총 28칸. 권장 생성 크기 1024×1792(한 칸 256×256). 다른 해상도도 같은 격자이면 가능하다.
- 위에서부터 **대기 → 걷기 → 공격 → 점프 → 앉기 → 피격 → 쓰러짐**. 한 행은 해당 동작의 연속 4프레임이다.
- 각 칸에 캐릭터 한 마리/한 명이 온전히 들어가며 칸 사이 여백·글자·격자선이 없어야 한다. 투명 PNG, 일정한 캐릭터 크기·방향·발 기준선을 요청한다.
- 기존 시트가 1~8열이면 **시트 격자 설정 → 가로 칸 수**를 맞춘다. 세로는 7행이다. 행 순서가 다르면 이미지 편집 도구에서 먼저 맞춘다.
- 불투명한 단색 배경만 **단색 배경 제거**로 보조 처리한다. 실제 이미지에 그려진 체크무늬는 투명 배경이 아니며 자동으로 지우지 않는다.

가져오기는 이미지 전체를 격자 칸으로 나눈다. **신체를 부위별로 분할하지 않는다.** 각 칸의 전체 캐릭터를 공통 배율로 축소하고 아래 중앙에 정렬해 96×96 칸의 게임 시트로 만든다. 4열 결과는 384×672이며 각 동작의 row·frames·fps를 자동 설정한다. 빈 칸은 적용 전에 거부한다. 원본 시트 전체 대신 정리한 게임용 PNG를 프로젝트에 저장한다. 재가져오기는 원래 PNG 파일을 보관해 사용한다.

## 펭귄 몸이 이미 갈라진 경우

기존 전신 원본이 있으면 **기본 움직임 방식 · 부위 경계 · 색상 · 크기 조정 → 전체 그림 유지 → 동작 다시 생성해 적용**으로 복원한다. 새 원본 등록의 기본값도 전체 그림 유지다. 기본 움직임은 몸 전체의 기울기·상하 이동·축소만 적용하는 로컬 임시 표현이며, 새 걷기·공격 자세를 그리지는 않는다. 실제 자세는 ChatGPT 시트 또는 직접 그린 완성 시트를 사용한다.

**사람형 부위 분할 (고급)**은 사람이 직접 선택했을 때만 사용한다. 기존 컷아웃 프로젝트의 방식은 자동 변경하지 않으므로 위 설정으로 전환한다. 기존 전투 판정·피해량·이동·스토리·저장 형식은 유지한다.

## AI 결과의 검수

요청문이 있어도 AI가 정확한 격자·프레임 수·투명도·동일한 인물과 체형을 항상 지키지는 않는다. 자동 격자 가져오기는 이미지가 실제로 어떤 동작인지 이해하거나 잘못 그린 팔다리를 복구하지 않는다. 미리보기에서 잘림·칸 경계·프레임마다 바뀐 크기·분리된 신체를 확인하고, 문제가 있으면 ChatGPT에 해당 행·격자를 고쳐 달라고 요청하거나 이미지 편집 도구에서 정리한다.

에디터 안에서 한 번에 AI를 호출하는 자동 생성은 이번 방식에 포함하지 않는다. 후속 자동 연동에는 인증·이미지 전송·비용 관리가 가능한 별도 API 구성이 필요하다. 공식 참고: [OpenAI 이미지 생성·참조 이미지 편집](https://developers.openai.com/api/docs/guides/image-generation), [ChatGPT 로그인 기반 추론의 이미지 생성 도구 제약](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations).
