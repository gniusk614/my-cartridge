# 첫 빌드 검증 기록

아래는 최초 빌드 기록이다. 최신 모바일 UX 빌드는 **Godot 101개 검사, 웹 셸 15개 검사, 기존 봇 완주 10회를 통과**했다. 모바일 추가 결과는 [MOBILE_UX.md](MOBILE_UX.md)를 따른다. 화면 관련 결과는 [전체화면 변경 기록](FULLSCREEN.md), 이전 이동 기능 결과는 [이동과 탐색 추가 기록](TRAVERSAL_UPDATE.md)을 따른다.

검증일은 2026년 11월 10일이다. 실행 엔진은 공식 Godot `4.7.2.stable.official.ed1daf0bf` macOS universal 배포본이다. 이 기록은 기술 시제품의 자동·브라우저 검증이며 출시 승인이나 사람의 플레이 테스트를 대체하지 않는다.

## 자동 검사 범위

잘못된 필드 타입, 경로형 ID, 순환 등장 의존성, 없는 단서, 달성 불가능 처치 수, 불허 메커니즘, 플레이어 역할 수, 중복 ID를 거부했다. 처치 전 단서 잠금, 중복 처치와 수집 방지, 목표 재계산, 손상 저장 복구, 개정 불일치 격리, 저장 후 복원도 확인했다.

전투 검사는 동일 공격의 중복 피해 방지, 방향·y-depth 빗나감, 실제 Area2D 겹침과 적 AI를 통과하는 완주를 포함한다. 일시정지 시 이동 중단, 대각선 정규화, 경계 고정, 사망 상태와 재도전 시 기억·목표 보존을 추가로 검사했다.

| 자동 완주 횟수 | 팩 | 물리 프레임 |
|---|---|---|
| 1, 4, 7, 10 | 카페 영수증 | 각 791 |
| 2, 5, 8 | 파란 우산 | 각 976 |
| 3, 6, 9 | 일출 사진 | 각 849 |

60 Hz 고정 델타 기준으로 약 13.2~16.3초의 게임 시간이다. 봇은 대사를 즉시 넘기고 최적 경로로 이동하므로 사람의 플레이 시간과 같지 않다. 목표 분량 2~4분이 충족됐다고 해석하지 않는다.

## 브라우저 QA에서 수정한 항목

좁은 화면에서 메뉴 하단이 잘려 팩 선택을 드롭다운으로 바꾸고 팝업을 스크롤 가능하게 했다. 기본 ProgressBar 테마의 큰 최소 높이를 제거하고 아래쪽 방향 버튼을 내부 뷰포트 경계 안으로 옮겼다. 한국어 폰트와 라이선스를 웹 팩에 동봉했다.

## 아직 검증하지 않은 항목

- iPhone Safari 및 Android Chrome 실기기, 이동과 공격 동시 멀티터치.
- 가로 회전, 안전영역·노치, 전체화면, 시스템 인터럽트 및 앱 복귀.
- 실제 장치의 오디오 출력·최초 사용자 제스처·음소거·재개 품질.
- 브라우저 새로고침 후 IndexedDB 저장 지속성, 저장 한도·사생활 보호 모드.
- 실제 모바일 FPS, 입력 지연, 느린 네트워크 초기 로딩, 압축·캐시 전송량.
- 사람의 전투 재미, 2~4분 분량, 3~5명 사용자 체험.

초기 웹 빌드는 wasm 약 38 MiB, pck 약 6.5 MiB로 최적화 전이다. 파일 크기는 전송 압축 전 정적 크기이며 로딩 시간·실제 전송량은 측정하지 않았다. 플랫폼·결제·AI·실제 고객 콘텐츠·협동 서버는 구현하거나 검사하지 않았다.
