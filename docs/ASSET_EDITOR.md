# 개체와 에셋 편집기 1.2

2026-11-10 제작 중 개체 배치가 어렵다는 피드백을 반영했다. 기본 흐름은 **박스 먼저 배치 → 썸네일로 그림 교체**다. 에셋을 먼저 등록해 새 개체로 추가하는 흐름도 함께 지원한다.

## 가장 빠른 사용법

1. **맵과 장면 → ＋ 장식 박스**를 누른다. 현재 보이는 맵의 빈 위치를 찾아 기본 박스를 추가하고 선택한다.
2. 맵 아래 **박스를 이미지로 바꾸기**에서 나무·벤치·화분·가로등·표지판 썸네일을 누른다. 위치·크기·좌우 반전·앞뒤 순서는 유지하고 그림만 바뀐다.
3. 내 그림을 쓰려면 **＋ 내 이미지로 바꾸기**에서 PNG·JPEG·WebP를 고른다. 이미지 등록과 선택한 박스 적용을 한 번에 처리한다.
4. **위치·크기·겹침 설정**을 펼치면 좌표, 그림 너비·높이, 캐릭터 앞/뒤, 좌우 반전을 조정한다. 빈 박스로 되돌릴 때는 **기본 박스**를 누른다.
5. **검증 → 플레이**로 실제 게임에서 확인하고 JSON 또는 게임 ZIP을 저장한다. 그림 없는 박스도 저장·실행할 수 있다.

박스, 기억, 대화 인물, 적, 발판은 버튼 한 번으로 추가된다. 맵에서 선택해 끌어 이동하고, 선택한 개체의 **복제/삭제**, 맵 위 **실행 취소/다시 실행**을 사용한다. 실행 취소는 현재 프로젝트의 최근 20개 편집 기록이며 브라우저를 새로 열면 초기화된다. 프로젝트 변경·JSON 불러오기 시 다른 프로젝트의 기록을 적용하지 않는다.

기억을 선택하면 이름과 발견 내용을, 대화 인물을 선택하면 캐릭터와 대사를 맵 아래에서 바로 편집한다. 정확히 위치를 찍어 추가하는 기존 도구는 **맵을 직접 찍어서 배치하기**에 있다. 화면 확대 기본값은 150%이며, 장면 선택 메뉴는 좁은 화면에도 표시한다.

## 에셋 보관함

**에셋 보관함**에서 종류를 고르고 여러 이미지를 한 번에 등록한다. 파일을 등록 영역으로 끌어 놓을 수도 있다. 에셋 이름·썸네일·크기·사용 횟수가 표시된다.

| 종류 | 사용 방법 |
|---|---|
| 장식 | 새 장식으로 맵에 추가, 선택한 박스에 적용, 맵 바로 위 이미지 목록에서 드래그 배치 |
| 배경 | 현재 편집 중인 장면의 배경으로 연결 |
| 초상화 | 보관함의 인물 적용 대상을 고른 뒤 해당 인물의 초상화로 연결 |
| 캐릭터 동작 | 인물 적용 대상을 고른 뒤 PNG 스프라이트시트 연결. 연결 뒤 캐릭터 공방에서 칸 크기와 동작 행·프레임·FPS 조정 |

같은 장식 이미지는 여러 장면·여러 박스에서 재사용한다. 맵에 파일을 직접 끌어 놓으면 장식 이미지로 등록하고 해당 위치에 배치한다. 사용 중인 에셋은 삭제 버튼을 막으며, 사용하지 않는 에셋은 삭제하거나 **검증과 전달 → 연결되지 않은 에셋 정리**로 정리한다. 이미지와 초안은 브라우저에서 처리·저장하며 서버로 보내지 않는다.

## 지원 범위와 제한

- 새 팩은 스키마 1.2.0이다. 기존 1.0.0 게임과 1.1.0 에피소드는 계속 읽고, 스튜디오에서 편집 시 1.2.0으로 변환한다. 팩 ID·개정·이야기·진행 ID는 유지한다.
- 장면당 장식 64개, 프로젝트 PNG 에셋 32개. 기존 PNG 한 항목 2,000,000자, 전체 12,000,000자·8,388,608픽셀 한도를 유지한다.
- 입력 파일은 12 MB 이하 PNG·JPEG·WebP. 장식은 긴 변 최대 512픽셀로 축소해 등록한다. 배경·초상화는 최대 2048, PNG 시트는 원본 8~2048 범위다. 모든 저장 이미지는 PNG로 변환한다.
- 보관함의 PNG 동작 시트 등록은 기본 32×48 격자를 사용한다. 다른 격자는 캐릭터 공방에서 등록하고 조정한다.
- 장식 박스와 장식 이미지는 충돌·대화·아이템 획득 기능이 없는 시각 개체다. 점프와 착지가 필요한 지형은 **발판**, 이야기는 **기억/대화 인물**을 사용한다. 정적 이미지를 적용해 전투·점프 동작을 자동 생성하지 않는다.
- 기본 소품은 프로젝트에서 코드로 그린 원본 픽셀 템플릿이다. 배경/동작/초상화 역할 연결과 외부 리소스 이용 권한은 제작자가 확인한다.
- 게임 ZIP과 JSON에 고객 이미지도 포함된다. 고객별 접근 권한에 맞춰 전달·호스팅한다. 공개 사이트에 자동 게시하지 않는다.

## 검증

단위 검사에서 빈 박스의 생성·이미지 적용·해제, 맵 경계 보정, 공유 에셋 참조, 잘못된 kind·ID·버전과 기존 초안 업그레이드를 검사한다. Godot에서 실제 PNG·빈 박스 렌더링, 비정수 배율, 좌우 반전·앞뒤 순서, 실내 진입 시 외부 장식 숨김을 검사한다.

Chromium·WebKit에서 박스 배치 → 내 이미지 등록/교체 → 위치 보존 → 복제/삭제/실행 취소 → JSON 재불러오기 → 실제 게임 렌더러 적용을 검사한다. 여러 이미지 등록·다른 장면에서 재사용·맵으로 드래그·배경/초상화/시트 연결과 좁은 터치 화면의 좌표 입력 없는 교체도 포함한다. 기존 모바일 입력·전투·저장·독립 ZIP 검사도 유지한다.
