# 임시 에셋과 권리

거리, 눈, 조명, 캐릭터, 공격 궤적, 단서와 버튼은 이 프로젝트에서 새로 작성한 Godot 그리기 코드로 만든 임시 표현이다. 다른 게임의 캐릭터·맵·음악을 복사하지 않았다. 최종 아트나 30프레임 스프라이트 시트를 납품한 상태는 아니다.

`demo_ending.wav`는 22050 Hz mono 16-bit PCM의 단순 사인파 멜로디다. 이 작업에서 임시로 만든 음원이며 고객 맞춤 노래가 아니다. 웹에서 런타임 합성에 의존하지 않고 파일로 재생한다. headless 검사는 음향 재생을 생략한다.

한국어 폰트는 Google Fonts의 Noto Sans KR이다. `game/assets/fonts/OFL.txt`에 SIL Open Font License를 동봉했다. 출처는 https://github.com/google/fonts/tree/main/ofl/notosanskr 이다. 배포할 때 라이선스를 유지한다.

Godot 엔진과 export templates는 공식 4.7.2 배포본을 사용했다. 작업 중 받은 에디터 및 전체 템플릿 압축파일은 소스 결과물 밖의 work/tools에 두었다. 웹 실행 파일은 build/web에 있다.
